- :white_check_mark: Add code to your GitHub Page

- :white_check_mark: How to update your code on GitHub with GitHub Desktop
- :white_check_mark: How to retrieve your most recent changes that were submitted to GitHub and put them on your computer

## Before Anything

> Create a [GitHub account](https://github.com/signup)
> Download GitHub desktop [here](https://desktop.github.com/)
> Login to GitHub Desktop using your [GitHub Account](https://github.com/login)

## Adding Code to GitHub

Open GitHub Desktop.

Click on `Create a New Repository on your local drive...`

In the first text input field, give your repository a name.

> [!Note]
> A repository is a place where you store things, in this case it will contain code files, assets, other folders, etc...

Add a description of what this repositry will be such as a website, app, or game.

Make sure to check `Initialize this repository with a README`

Under the `Git ignore` dropdown, select the template you are using.
* For example if you made your project using Unity, you will select Unity.

Under the `License` dropdown, select `MIT License`.

Click on `Create repository`.

Click on `Publish repository` and then once more.

## Start Coding

Click the first option that says “Open In (Whatever You Use To Edit Code)” and then code away using your editor!

> [!Note]
> If you already have files that are ready to be uploaded to GitHub, then click `Show In explorer` and drag all your projects files into there.

## Update Your Code on GitHub from GitHub Desktop

Make sure in the top left that all the files you want on GitHub are selected.

When you are done making changes and want to update it on GitHub, go back to GitHub Desktop and in the bottom left, Fill out the first text field with a summary or message of what files you added or what major change occur (only a couple words)

You can add a description to be more specific but this field unlike the previous is not required.

Click `Commit to main` then in the middle of the screen `Push origin`.

##  Retrieve Your Most Recent Changes That Were Submitted To GitHub

If this is your first time retrieving a certain repositry from GitHub (meaning if you click the name of the current repository you are working on and it is not listed, **then select `Add` -> `Clone repository...`**

Select the repository that is stored on GitHub that you want to copy/clone to your computer and then click `Clone`.

If you have never cloned anything to your computer using GitHub Desktop, then you can just click `Clone a repository from the internet...`

On GitHub Desktop, in the top of your screen click on “Fetch origin” which takes the most recent changes on GitHub and puts that on your computer.
> [!Warning]
> If you have made **ANY CHANGES** to a reposity, you will have stash those changes away or submit them to be able to fetch from GitHub

***YOU ALWAYS WANT TO FETCH ORIGIN TO MAKE SURE WHAT EVER CODE YOU WILL BE WORKING ON IS THE MOST RECENT VERSION***

***YOU SHOULD BE PUSHING YOUR WORK TO GITHUB FREQUENTLY AND ALWAYS PUSH RIGHT BEFORE YOU ARE DONE WORKING FOR THE DAY***
